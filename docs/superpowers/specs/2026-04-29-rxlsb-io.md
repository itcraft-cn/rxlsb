## 一、BufferReader

### 1.1 结构定义

```rust
use bytes::Bytes;

pub struct BufferReader {
    buffer: Bytes,
    position: usize,
}

impl BufferReader {
    pub fn new(buffer: Bytes) -> Self {
        Self { buffer, position: 0 }
    }
    
    pub fn from_slice(slice: &[u8]) -> Self {
        Self::new(Bytes::copy_from_slice(slice))
    }
}
```

### 1.2 基本读取方法

```rust
impl BufferReader {
    pub fn read_byte(&mut self) -> Result<u8> {
        if self.position >= self.buffer.len() {
            return Err(XlsbError::BufferOverflow {
                position: self.position,
                length: self.buffer.len(),
            });
        }
        let b = self.buffer[self.position];
        self.position += 1;
        Ok(b)
    }
    
    pub fn read_u8(&mut self) -> Result<u8> {
        self.read_byte()
    }
    
    pub fn read_u16_le(&mut self) -> Result<u16> {
        if self.position + 2 > self.buffer.len() {
            return Err(XlsbError::BufferOverflow {
                position: self.position,
                length: self.buffer.len(),
            });
        }
        let bytes = &self.buffer[self.position..self.position + 2];
        let value = u16::from_le_bytes([bytes[0], bytes[1]]);
        self.position += 2;
        Ok(value)
    }
    
    pub fn read_u32_le(&mut self) -> Result<u32> {
        if self.position + 4 > self.buffer.len() {
            return Err(XlsbError::BufferOverflow {
                position: self.position,
                length: self.buffer.len(),
            });
        }
        let bytes = &self.buffer[self.position..self.position + 4];
        let value = u32::from_le_bytes([bytes[0], bytes[1], bytes[2], bytes[3]]);
        self.position += 4;
        Ok(value)
    }
    
    pub fn read_u64_le(&mut self) -> Result<u64> {
        if self.position + 8 > self.buffer.len() {
            return Err(XlsbError::BufferOverflow {
                position: self.position,
                length: self.buffer.len(),
            });
        }
        let bytes = &self.buffer[self.position..self.position + 8];
        let value = u64::from_le_bytes([
            bytes[0], bytes[1], bytes[2], bytes[3],
            bytes[4], bytes[5], bytes[6], bytes[7],
        ]);
        self.position += 8;
        Ok(value)
    }
    
    pub fn read_f64_le(&mut self) -> Result<f64> {
        let bits = self.read_u64_le()?;
        Ok(f64::from_bits(bits))
    }
    
    pub fn read_i32_le(&mut self) -> Result<i32> {
        let u = self.read_u32_le()?;
        Ok(u as i32)
    }
}
```

### 1.3 批量读取

```rust
impl BufferReader {
    pub fn read_bytes(&mut self, len: usize) -> Result<Bytes> {
        if self.position + len > self.buffer.len() {
            return Err(XlsbError::BufferOverflow {
                position: self.position,
                length: self.buffer.len(),
            });
        }
        let slice = self.buffer.slice(self.position..self.position + len);
        self.position += len;
        Ok(slice)
    }
    
    pub fn read_slice(&mut self, len: usize) -> Result<&[u8]> {
        if self.position + len > self.buffer.len() {
            return Err(XlsbError::BufferOverflow {
                position: self.position,
                length: self.buffer.len(),
            });
        }
        let slice = &self.buffer[self.position..self.position + len];
        self.position += len;
        Ok(slice)
    }
    
    pub fn skip(&mut self, len: usize) -> Result<()> {
        if self.position + len > self.buffer.len() {
            return Err(XlsbError::BufferOverflow {
                position: self.position,
                length: self.buffer.len(),
            });
        }
        self.position += len;
        Ok(())
    }
}
```

### 1.4 状态查询

```rust
        self.position = 0;
    }
```

## 三、VarInt编解码

### 3.1 VarInt编码规则

BIFF12使用变长整数（VarInt）编码，规则如下：
- 每字节最高位（bit 7）表示是否继续
- 低7位（bit 0-6）存储数据
- 小端序编码

示例：
- 值 0x00-0x7F: 1字节 (0x00-0x7F)
- 值 0x80-0x3FFF: 2字节 (0x80 0x01-0xBF 0x3F)
- 值 0x4000-0x1FFFFF: 3字节

### 3.2 BufferWriter VarInt写入

```rust
impl BufferWriter {
    pub fn write_varint(&mut self, value: u32) -> usize {
        let mut written = 0;
        let mut v = value;
        
        loop {
            let byte = (v & 0x7F) as u8;
            v >>= 7;
            
            if v != 0 {
                self.write_byte(byte | 0x80);
                written += 1;
            } else {
                self.write_byte(byte);
                written += 1;
                break;
            }
        }
        
        written
    }
    
    pub fn write_varsize(&mut self, value: u32) -> usize {
        self.write_varint(value)
    }
    
    pub fn varint_size(value: u32) -> usize {
        if value < 0x80 { 1 }
        else if value < 0x4000 { 2 }
        else if value < 0x200000 { 3 }
        else if value < 0x10000000 { 4 }
        else { 5 }
    }
}
```

### 3.3 BufferReader VarInt读取

```rust
impl BufferReader {
    pub fn read_varint(&mut self) -> Result<u32> {
        let mut result = 0u32;
        let mut shift = 0;
        
        loop {
            let byte = self.read_byte()?;
            result |= ((byte & 0x7F) as u32) << shift;
            
            if byte & 0x80 == 0 {
                break;
            }
            
            shift += 7;
            
            if shift >= 32 {
                return Err(XlsbError::InvalidVarInt);
            }
        }
        
        Ok(result)
    }
    
    pub fn read_varsize(&mut self) -> Result<u32> {
        self.read_varint()
    }
}
```

## 四、UTF-16LE处理

### 4.1 UTF-8到UTF-16LE转换

BIFF12字符串使用UTF-16LE编码。

```rust
impl BufferWriter {
    pub fn write_wide_string(&mut self, s: &str) -> usize {
        let utf16_chars: Vec<u16> = s.encode_utf16().collect();
        let char_count = utf16_chars.len() as u32;
        
        self.write_varsize(char_count);
        
        for ch in utf16_chars {
            self.write_u16_le(ch);
        }
        
        self.varint_size(char_count) + char_count as usize * 2
    }
    
    pub fn utf16le_length(s: &str) -> usize {
        s.encode_utf16().count()
    }
    
    pub fn utf16le_byte_length(s: &str) -> usize {
        s.encode_utf16().count() * 2
    }
}
```

### 4.2 UTF-16LE到UTF-8转换

```rust
impl BufferReader {
    pub fn read_wide_string(&mut self) -> Result<String> {
        let char_count = self.read_varsize()? as usize;
        let byte_count = char_count * 2;
        
        if self.position + byte_count > self.buffer.len() {
            return Err(XlsbError::BufferOverflow {
                position: self.position,
                length: self.buffer.len(),
            });
        }
        
        let bytes = self.read_bytes(byte_count)?;
        decode_utf16le(&bytes)
    }
}

fn decode_utf16le(bytes: &Bytes) -> Result<String> {
    let chars: Vec<u16> = bytes.chunks_exact(2)
        .map(|chunk| u16::from_le_bytes([chunk[0], chunk[1]]))
        .collect();
    
    String::from_utf16(&chars)
        .map_err(|_| XlsbError::InvalidUtf16)
}

fn encode_utf16le(s: &str) -> Vec<u8> {
    s.encode_utf16()
        .flat_map(|c| c.to_le_bytes())
        .collect()
}
```

### 4.3 辅助函数

```rust
pub fn is_surrogate_pair(first: u16, second: u16) -> bool {
    (0xD800..=0xDBFF).contains(&first) && (0xDC00..=0xDFFF).contains(&second)
}

pub fn decode_surrogate_pair(first: u16, second: u16) -> char {
    let code_point = (((first - 0xD800) as u32) << 10) + (second - 0xDC00) as u32 + 0x10000;
    char::from_u32(code_point).unwrap_or('\0')
}
```

## 五、Excel日期序列转换

### 5.1 转换规则

Excel使用浮点数表示日期：
- 整数部分：自1899-12-30的天数
- 小数部分：一天中的时间比例
- 注意：Excel错误地认为1900是闰年

### 5.2 DateTime转Excel序列

```rust
use chrono::{DateTime, Utc, TimeZone};

pub fn excel_date_serial(dt: &DateTime<Utc>) -> f64 {
    let excel_epoch = Utc.with_ymd_and_hms(1899, 12, 30, 0, 0, 0).unwrap();
    let duration = dt.signed_duration_since(excel_epoch);
    
    let days = duration.num_days() as f64;
    let seconds = duration.num_seconds() % 86400;
    let fractional_day = seconds as f64 / 86400.0;
    
    days + fractional_day
}
```

### 5.3 Excel序列转DateTime

```rust
pub fn excel_serial_to_date(serial: f64) -> DateTime<Utc> {
    let excel_epoch = Utc.with_ymd_and_hms(1899, 12, 30, 0, 0, 0).unwrap();
    
    let days = serial as i64;
    let fractional = serial - days as f64;
    let seconds = (fractional * 86400.0) as i64;
    
    excel_epoch + chrono::Duration::days(days) + chrono::Duration::seconds(seconds)
}
```

## 六、性能优化

### 6.1 Bytes池化

bytes crate内部使用内存池：
- BytesMut分配后可多次使用
- freeze()转换为Bytes后仍共享底层内存
- split()操作零拷贝

### 6.2 预分配策略

```rust
impl BufferWriter {
    pub fn preallocate_for_rows(row_count: usize, col_count: usize) -> Self {
        let estimated_size = row_count * col_count * 20;  // 平均每单元格20字节
        Self::new(estimated_size)
    }
}
```

### 6.3 零拷贝读取

```rust
impl BufferReader {
    pub fn slice_at(&self, pos: usize, len: usize) -> Option<Bytes> {
        if pos + len > self.buffer.len() {
            return None;
        }
        Some(self.buffer.slice(pos..pos + len))
    }
    
    pub fn slice_remaining(&self) -> Bytes {
        self.buffer.slice(self.position..)
    }
```
